# Profile design notes

The existing animated `readme-aura` hero keeps its layout, content, and eight moving glow paths; its palette is now grayscale to match the halftone banner above it. Everything below follows the section rhythm of [midnightshady/midnightshady](https://github.com/midnightshady/midnightshady): compact intro, About, Connect, Tech Stack, work, stats, contribution art, and closing philosophy. A [fork](https://github.com/Adityax-07/midnightshady) is kept as the reference copy.

The reference repository does not provide a reuse license. Its illustrations were **not** copied into this profile. `assets/astronaut-original.png` is the original generated character reference. The About section now floats `assets/astronaut-wave.gif` to the right at 170 px; its 12-frame, 240 px transparent loop is about 508 KB and starts on a waving pose so the still first frame is meaningful. The sprite sheet was generated with the built-in image tool from the original character using the prompt: “Six equal transparent frames of the same grayscale, dotted halftone astronaut turning toward the viewer, raising one gloved hand, waving, then lowering it; preserve the helmet, visor, backpack, suit panels, scale, and baseline; no background, text, extra limbs, or other characters.”

The project claims link directly to the public repositories. The activity graph from the reference layout was skipped because its endpoint returned HTTP 402 during verification. The remaining GitHub streak widget and icon rows are decorative; their content has text equivalents. Pac-Man light/dark SVGs are generated in this repository's `output` branch by the scheduled workflow. The closing line is static to avoid a random quote service.

The tech icon rows are self-hosted copies generated from [skill-icons](https://github.com/tandpfun/skill-icons) and include its [MIT license](assets/SKILL_ICONS_LICENSE.txt). Remaining external runtime dependencies: `streak-stats.demolab.com` for the streak and GitHub's raw content host for generated Pac-Man SVGs. The workflow uses versioned `abozanona/pacman-contribution-graph@v5.0.0` and `crazy-max/ghaction-github-pages@v5`; the hero renderer is pinned to `readme-aura@1.0.4`. All content remains legible if decorative images fail.

The expanded row adds Streamlit, Hugging Face, LangChain, LangGraph, FAISS, and vLLM without claiming any new skills. Five marks come from [Simple Icons](https://github.com/simple-icons/simple-icons); FAISS uses a custom vector-search glyph rather than an unofficial logo. Their local sources and attribution are in `assets/brand-icons/`, and `scripts/build_stack_icons.py` rebuilds the two additional strips.

To refresh assets manually: run the **Generate Pac-Man contribution graph** and **readme-aura** workflows in Actions. The source README is `readme.source.md`; edit that file as well as the generated `README.md` when changing prose below the hero.
